# Meu Portfólio
Site estático de portfólio pessoal, com meus projetos (concluídos e em desenvolvimento), experiência profissional e formas de contato.

**AcessO:** [lucasbroliveiraa-arch.github.io/meu-portfolio](#)

## Sobre
Este projeto foi criado para reunir em um só lugar os projetos que venho desenvolvendo, 
minha trajetória profissional e um jeito fácil de me encontrar. Serve como vitrine 
para os demais projetos do meu portfólio.

## Tecnologias
- HTML5
- CSS3 (Flexbox/Grid)
- JavaScript

## Guia de Como Rodar Localmente
```bash
git clone https://github.com/lucasbroliveiraa-arch/meu-portfolio.git
cd meu-portfolio
```

Depois é só abrir o `index.html` no navegador (ou usar uma extensão como Live Server no VS Code).
